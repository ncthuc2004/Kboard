# Kboard Release v1.1.4 (versionCode 6)

## Điểm mới trong phiên bản v1.1.4:
1. **Thương hiệu & Tên ứng dụng mới:** Đổi tên chính thức thành **Kboard** (Bàn phím hệ thống: `Kboard LAN Keyboard`).
2. **Logo mới Full-Bleed 100%:** Triệt tiêu hoàn toàn lỗi viền trắng trên mọi giao diện Android (MIUI, HyperOS, OneUI, Pixel).
3. **Phím tắt trong App Clone:** Hoạt động mượt mà cho các tổ hợp phím `Ctrl+C`, `Ctrl+V`, `Ctrl+A`, `Ctrl+X`, `Ctrl+Z` qua `InputMethodService`.
4. **Bộ gõ Tiếng Việt Telex tích hợp:** Tự động bỏ dấu tiếng Việt chuẩn xác với nút bật/tắt nhanh `[ Telex: BẬT ]` / `[ Telex: TẮT ]`.
5. **Đè phím lặp ký tự (Hardware Key Repeat):** Giữ phím quá 380ms sẽ lặp liên tục tốc độ 45ms (~22 ký tự/giây) như phím cơ thật.
6. **Làm sạch mã nguồn:** Loại bỏ 100% tên thiết bị hardcode và toàn bộ icon emoji.

## Tệp đính kèm trong thư mục:
* `Kboard_v1.1.4.apk`: Bản cài đặt Android (API 28+).
* `Kboard.apk`: File cài đặt chuẩn.
* `Kboard_Receiver.exe`: Bộ nhận phím độc lập cho máy tính Windows (đã tích hợp icon mới).
